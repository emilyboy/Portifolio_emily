💻 Portfólio Web - Emily Carvalho
📖 Sobre o Projeto

Este projeto consiste em uma página de Portfólio / Currículo Web, desenvolvida em HTML, com o objetivo de apresentar informações pessoais, habilidades, projetos realizados e formas de contato.

A página foi criada durante o curso de Desenvolvimento de Sistemas no SENAI, utilizando uma estrutura HTML semântica e organizada.

🎯 Objetivo

O objetivo do projeto é desenvolver uma página web simples e funcional que apresente o perfil profissional da desenvolvedora, seus conhecimentos, projetos e informações para contato.

Além disso, o projeto permite praticar conceitos importantes de HTML5, como organização de conteúdo, links, imagens, tabelas, listas e formulários.

🛠️ Tecnologias Utilizadas
HTML5 — estrutura e organização da página.
CSS3 — conhecimento utilizado no desenvolvimento web.
JavaScript — tecnologia que está sendo estudada.
GitHub — utilizado para armazenar e compartilhar os projetos.

🖼️ Imagem

imagem/emily (2).png

🚀 Como Executar o Projeto
Baixe ou clone este repositório.
Abra a pasta do projeto.
Verifique se a pasta imagem está presente.
Abra o arquivo HTML em um navegador.
Navegue pelas seções Sobre, Projetos e Contato.
